# Open Source Security and System Audit Toolkit

This project is a Linux-based system auditing toolkit developed using Bash scripting. The toolkit performs basic security and system checks by analyzing important directories, file permissions, installed packages, and system logs. It helps users understand the current state of their Linux system and identify potential security risks or misconfigurations.

The scripts automate common system administration tasks that are normally performed manually. By using standard Linux commands and shell scripting, the toolkit demonstrates how open source tools can be used to monitor system information, inspect file permissions, and analyze system activity. This project also demonstrates the use of Git for version control and collaborative open-source development.

## Features

- Disk and directory permission auditing
- System information collection
- Log file analysis
- Package inspection
- Lightweight Bash-based toolkit

## Technologies Used

- Bash Shell Scripting
- Linux Command Line Tools
- Git Version Control

```

```

3. Give execute permission to scripts
```

4. Run any script
```
